## Featured Projects

### 🏦 BrokerCraft — Distributed Stock Brokerage System

<a href="https://github.com/Sefefed/BrokerCraft">
  <img src="https://img.shields.io/badge/Explore%20Repository-BrokerCraft-181717?style=for-the-badge&logo=github&logoColor=white" alt="Explore BrokerCraft" />
</a>

A Java-based brokerage application that models client, broker, and administrator interactions through a distributed client-server architecture.

- **Distributed communication:** Java RMI between application components.
- **Concurrency control:** Per-client locking to coordinate concurrent transactions.
- **Persistence:** MySQL-backed application data.
- **Market simulation:** Geometric Brownian Motion for stock-price modeling.

`Java 17` `Java RMI` `Concurrency` `MySQL`

### 💸 Renewly — AI-Powered Finance Copilot

<a href="https://github.com/Sefefed/RENEWLY">
  <img src="https://img.shields.io/badge/Explore%20Repository-Renewly-181717?style=for-the-badge&logo=github&logoColor=white" alt="Explore Renewly" />
</a>

A full-stack personal finance application for managing subscriptions, bills, budgets, and financial decisions with AI-assisted insights.

- **Full-stack architecture:** React frontend with a Node.js and Express backend.
- **Authentication:** JWT-based authentication.
- **Data management:** MongoDB persistence.
- **AI integration:** Google Gemini through a provider-oriented LLM integration layer.
- **Finance workflows:** Subscription tracking, budgets, alerts, and AI-generated summaries.

`React` `Node.js` `Express` `MongoDB` `Google Gemini`
